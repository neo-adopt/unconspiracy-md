# unconspiracy-md

Small, practical review files for developers building agents at the edge of useful AI.

These checklists are designed to be copied into a project, adapted to its context, and used during agent design or review. They favor evidence over claims.

## Files

- [`only_you.md`](checklists/only_you.md) — the **Only yoU can beat AI** edition. Applies Read more, Write more, Meet more, and Talk more to check how original material and lived experience shape the agent's work.
- [`5d_test.md`](checklists/5d_test.md) — applies Anirudh Badam's five-D framework: Disruptor, Delivering, Disintermediation, Deflation, and Diversification. Checks the agent's contribution and the developer's or company's short-term benefit.

## Suggested use

1. Complete the relevant checklist before release.
2. Link to evidence wherever a box is checked.
3. Treat an unsupported claim as unchecked.
4. Record a clear result using the checklist's outcome options. Mark missing evidence explicitly.
5. Re-run the review whenever the agent's sources, instructions, tools, or intended users change materially.

These files are advisory. Teams should adapt them to their field, risks, and obligations.
